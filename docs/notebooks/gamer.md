# N-body tests with GAMER

Source: https://pianistpy.com/docs/notebooks/gamer

The test problem of the isolated *N*-body runs of [Chiang+(2026d)](https://arxiv.org/abs/2610.28758), [Chiang et al. (2025)](https://doi.org/10.1093/mnras/staf1639) and [Chiang et al. (2026a)](https://doi.org/10.33232/001c.155367),
as a test problem of the [GAMER](https://doi.org/10.1093/mnras/sty2586) code with its analysis and plotting
scripts, is listed on the [Upcoming features](https://pianistpy.com/docs/project/upcoming-features) page.

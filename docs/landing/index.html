Anisotropic spherical models, truncated in phase space

PIANISTpy builds spherical, non-rotating, velocity-anisotropic equilibrium models, self-consistently truncated in phase space, for dark matter (sub)halos, dwarf galaxies, stellar spheroids and star clusters. The package provides distribution functions, particle initial conditions, various velocity profiles and line-of-sight observables, with JAX-based end-to-end differentiability for rapid gradient-based Monte Carlo inference.

Install

pip install pianistpy. Python 3.11 or later. Runs on the CPU everywhere, with optional GPU acceleration.

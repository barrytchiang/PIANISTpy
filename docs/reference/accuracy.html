Accuracy tables#

The accuracy grid is a fixed set of models, four tables of rows by columns, run unchanged at every release. Each model’s distribution function is inverted and its density \(\varrho_{\rm inv}\) computed back from it; the roundtrip error \(|(\varrho_{\rm inv} - \varrho)/\varrho|\), against the input profile \(\varrho\), is read at 513 radii, and a cell gives that error over \(10^{-4} < R < 10^{5}\) (\(R\) in scale radii):

  • its maximum, then its median, then the tier the result itself reports (goal: \(10^{-6}\) or less; ceiling: \(10^{-4}\) or less; warning: \(10^{-2}\) or less; refused: beyond, see Accuracy);

  • refused and the refusal’s name, where the package refuses the model (the full message is in the cell’s tooltip and in the CSV);

  • excluded where the anisotropy breaks the cusp bound \(\gamma \ge 2\beta_{\rm c}\) (computed, and recorded in the CSV). A Type II model without a truncation has its distribution function only above the energy \(P(R_{\rm a})\): its cell gives the tier the package reports over that support and the note “support above \(P(R_{\rm a})\)”, not the density’s roundtrip, which is no measure there.

A † marks a cell whose outcome is not the one the grid expects. The tables are at the default tier; the CSV holds every range the grid reads, the radius of each maximum and the compute times. The tables of earlier releases are on Accuracy by release.

The grid of ver. 0.9.9, run at d59731fb, whose numerical code is 52a0ef0b’s (cpu), the default tier: the full grid as CSV and its member list.

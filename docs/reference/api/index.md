# Functions by subpackage

Docstrings cite two documents. An equation of Chiang et al. (2026d) is cited by its own label in that paper,
for example “Chiang et al. (2026d), Eq. (B9)”. An equation, section or table of the technical notes is cited by its number, which carries the prefix “T:”, together with a fixed key in brackets, for
example “Eq. (T:2.4) [conditions]”, “Section T:2.3.1 [df-form]” or “Table T:2.1 [critical]”; the key is the
item’s label and does not change when the notes are revised and a number moves.

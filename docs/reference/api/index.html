Functions by subpackage#

Docstrings cite two documents by number. An equation, section or figure of Chiang+(2026d) is cited as “Chiang+(2026d), Eq. (B9)”, “Chiang+(2026d), Section 2.1” or “Chiang+(2026d), Fig. 14”. An equation, section or table of the Technical notes is cited by its number, which carries the prefix “T:”, for example “Eq. (T:2.4)”, “Section T:2.3.1” or “Table T:2.1”.

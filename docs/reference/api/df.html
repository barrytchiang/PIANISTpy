Distribution functions and models (pianistpy.df)#

Distribution functions and equilibrium models.

class pianistpy.df.Component(profile, anisotropy=<factory>, mass=1.0, name='component')#

One component of a model: a density profile with its anisotropy.

A model is a sequence of components that share one total potential. A single component is a sequence of length one.

Given the truncated profile of another model (parent.profile) in place of an analytic profile, the component is Method II of the paper: the density of the parent in the parent’s potential, with a new anisotropy. It is refused here where no distribution function exists for that anisotropy at the edge of the density.

A profile with an outer slope between 2 and 3 is refused here (OUTER SLOPE): the outer end of the inversion and its tail exponent assume Psi ~ 1/R, which that regime does not have.

Parameters:

  • profile (DoublePowerLaw or TruncatedProfile) – Density profile of the component: an analytic profile, or the truncated profile of a model of one component.

  • anisotropy (Anisotropy, optional) – Velocity anisotropy of the component. Isotropic by default.

  • mass (float, optional) – Mass of the component relative to the first component.

  • name (str, optional) – Label carried by the particles and the results of the component.

class pianistpy.df.DistributionFunction(components, settings, identity, grid, table, form, k_t_min, validation, timing, inversion, units=Units(system='internal', concentration=None, mass_0_msun=None, r_0_pc=None), rows=None, source='inversion', function_name=None)#

Untruncated distribution functions of the components of a model.

Returned by compute_df. It is a mathematical object: it may be negative or non-monotonic, and states where. Only a Model can be sampled or projected.

Parameters:

  • components (tuple of Component) – The components the DFs belong to.

  • settings (Settings) – The settings the DFs were computed with.

  • identity (str) – Identity string of the result.

  • grid (EnergyGrid) – The energies of the table and their radii.

  • table (DfTable) – The DFs on the grid.

  • form (AsymptoticForm) – The analytic form of each DF beyond the ends of its table.

  • k_t_min (float) – Lowest admissible truncation energy; zero where every DF is non-negative and non-decreasing. For a Type II model whose bound is its domain edge, the next float above P(R_a), the smallest K_t the gates admit; the truncated model’s edge must also lie inside R_a, which the truncation’s solve judges (TYPE II EDGE).

  • validation (ValidationReport) – The report of the inversion.

  • timing (dict of str to float) – Wall time of each stage, in seconds.

  • inversion (InversionRecord or None) – How the table was made; None where it was not made by an inversion (a closed form). Every solved DF states it.

  • rows (InversionRows or None) – The inversion’s rows as made on its whole grid, which the truncation reads; None where the table was not made by an inversion.

  • source (str) – Where the table’s values come from: "inversion" (compute_df) or "function" (from_function).

  • function_name (str or None) – The __name__ of the function the table was taken from; None for an inversion.

  • units (Units)

classmethod from_function(component, f, settings=None)#

Return the distribution function a function of the energy gives.

A user brings a DF (a fitting function, another code’s output) and the package certifies it against the density by its own integration. The function is tabulated on the energy grid compute_df places for the same component and settings, in place of the inversion’s values, and everything after runs as for the inversion: the forms beyond the table, the slope column, the sign report, the validation, the identity, and the file. The table is stored, the function is not.

Parameters:

  • component (Component) – The component the DF belongs to, on an analytic profile.

  • f (callable) – f(k, depth): takes the array of the energies K (the table’s, in internal units) and the array of their depths P_0 - K, and returns the DF at each, F and not its logarithm. The depth is the grid’s own P_0 - K of each node, exact, so a fit written in the depth near the center reads it directly; a function of K alone may ignore it.

  • settings (Settings, optional) – Numerical settings. The default tier if omitted.

Returns:

df – Its source is "function" and its function_name the function’s __name__. The table has no derivative column, and the report’s slope_column states that it is not judged. It has no inversion record and no rows, so truncate refuses it.

Return type:

DistributionFunction

Raises:

InputError – If the function is not finite somewhere on the grid (the first such K is stated), returns another shape, or the component is built on a tabulated profile.

write_text(path, overwrite=False)#

Write the DF table as fixed-width text, an export beside the file.

One row per node of each component’s support: the energy k (in units of the central potential, internal units), log10_df and the slope dlog10_df_dlnk of the table, and with more than one component its index in a component column. class pianistpy.df.Model(components, truncation, settings, identity, parent, table, form, profile, validation, timing, r_trust, inversion, units=Units(system='internal', concentration=None, mass_0_msun=None, r_0_pc=None))#

A valid equilibrium: truncated or untruncated, of one or more components.

Returned by truncate and solve. A model always has non-negative, non-decreasing DFs. Whether its density ends at a finite radius is a property of the model, spatially_finite.

Parameters:

  • components (tuple of Component) – The components of the model.

  • truncation (Truncation or None) – The truncation, or None for an untruncated model.

  • settings (Settings) – The settings the model was computed with.

  • identity (str) – Identity string of the result.

  • parent (str) – Identity string of the DistributionFunction the model was built from.

  • table (DfTable) – The DFs of the model.

  • form (AsymptoticForm) – The analytic form of each DF beyond the ends of its table.

  • profile (TruncatedProfile) – The self-consistent profile of the model.

  • validation (ValidationReport) – The report of the model.

  • timing (dict of str to float) – Wall time of each stage, in seconds.

  • r_trust (mapping of str to float) – The radius within which the model holds each accuracy tier, keyed by the report’s tier names (“goal”, “ceiling”; “limit” where it is computed): where the result is valid, not an error of it. Every tier or none: the radii are measured on an untruncated model, from the offset of its potential at large radii, and the mapping is empty on a truncated model (a spatially finite one holds its table to its edge) and where that offset is undefined. A tier the table’s first outer row already misses has radius 0; infinite on a closed form.

  • inversion (InversionRecord or None) – How the model’s table was made; None where it was not made by an inversion (a closed form). Every solved model states it.

  • units (Units)

property spatially_finite: bool#

Whether the density reaches zero at a finite radius and mass.

property diverges_at_zero: tuple[bool, ...]#

Whether the DF of each component diverges as the energy goes to zero.

See AsymptoticForm.diverges_at_zero. Such a model is a valid equilibrium with a finite density; its DF is not monotonic.

class pianistpy.df.Truncation(k_t=None, mass_t=None, r_t=None, concentration=None)#

How the distribution function of a model is truncated.

This is Method I of the paper. Method II needs no truncation: it is a component whose profile is the truncated profile of another model, given a new anisotropy.

Exactly one of k_t, mass_t and r_t is given. A target mass is given together with the concentration that defines its unit.

Parameters:

  • k_t (float, optional) – Truncation energy \(\mathcal{K}_{\rm t}\), in internal units (the central potential of the untruncated profile is 1).

  • mass_t (float, optional) – Target total mass of the truncated model, in MODEL units: in units of \(M_0\), the mass of the untruncated profile inside the concentration radius, so that a value of 1 is the virial mass. This is the one input that is not in internal units. The truncation energy is solved for. Requires concentration.

  • r_t (float, optional) – Target truncation radius \(R_{\rm t}\), in internal units (the scale radius \(r_0\) is their unit of length). The truncation energy is solved for.

  • concentration (float, optional) – Concentration \(c\) of the first component: \(M_0\) is the mass of its untruncated profile inside \(c\,r_0\). Required with mass_t, and refused with k_t and r_t, which do not depend on it.

pianistpy.df.compute_df(components, settings=None)#

Return the untruncated distribution function of each component.

The DF is returned whatever its sign, with the information needed to truncate it: where it is negative, its minimum, and the lowest admissible truncation energy.

Parameters:

  • components (Component or sequence of Component) – The component of the model. This release takes one; a sequence of several, in one total potential, is refused.

  • settings (Settings, optional) – Numerical settings. The default tier if omitted.

Returns:

df

Return type:

DistributionFunction

Raises:

NotImplementedError – If the component’s anisotropy family is not served yet (served: isotropic, constant beta and Osipkov-Merritt Type I).

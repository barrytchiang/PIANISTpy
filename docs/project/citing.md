# How to cite

Please cite the initial release paper, Chiang, van den Bosch and Schive (2026d), MNRAS, submitted (henceforth Chiang+(2026d)), in work that uses PIANISTpy. The
citation entry, the arXiv link and the DOI of the software release are added with ver. 1.0.0.

How to cite
===========

Please cite the initial release paper, |paper-full|, henceforth |paper|, in work that uses PIANISTpy.

Each release of PIANISTpy is also archived on Zenodo under
`doi:10.5281/zenodo.23548188 <https://doi.org/10.5281/zenodo.23548188>`__, which resolves to the latest release.

Technical notes
===============



This technical document details the analytical and numerical treatments implemented in PIANISTpy, building upon the high-level overviews provided in the initial code release paper of Chiang, van den Bosch and Schive (2026d), cited throughout as |paper|. Here, we follow and routinely refer to the notations, equations, and results of that paper. This document is organized by the objects of the pipeline, from upstream to downstream, and each object-specific section first treats the analytical theory (whenever applicable) and then the accompanying numerical implementations. :ref:`Section T:0 <tn-sec-principles>` states the conventions and notations used; we then discuss the input potential-density models (:ref:`Section T:1 <tn-sec-model>`), the distribution function (:ref:`Section T:2 <tn-sec-df>`), the truncation (:ref:`Section T:3 <tn-sec-truncation>`), the linear superposition of components (:ref:`Section T:4 <tn-sec-sup>`), the particle sampling (:ref:`Section T:5 <tn-sec-sampling>`), the velocity profiles and projections (:ref:`Section T:6 <tn-sec-observables>`), and the JAX-based gradients (:ref:`Section T:7 <tn-sec-gradients>`). :ref:`Section T:8 <tn-sec-verification>` documents the accuracy and validation tests and related information.
